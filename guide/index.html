    # 网站介绍：数学·编程·艺术·读书

    # 一、网站定位与愿景

    这是一个以链接为核心的知识聚合平台，用于收录我个人的微信公众号中关于数学、编程、艺术与读书四大领域的文章。网站旨在打破信息孤岛，将分散在不同公众号中的内容通过链接形式集中呈现，整理一个简洁、高效的知识导航站。

    # 二、内容分类体系

    # 1. 数学板块

    涵盖从小学到大学的所有数学知识。回归课本，不再以刷题提分为核心，而以真正的掌握数学奥秘，能够学以致用，让数学成为又意思的学科，能够通过建模解决我们日常生活中遇到的问题。

    # 2. 编程板块

    系统学习编程方面知识，参与信息学奥林匹克竞赛。

    # 3. 艺术板块

    艺术不是孤立的，它与数学的对称美、编程的结构美、书籍的思想美交相辉映。

    # 4. 读书板块

    从数学科普到编程经典，从艺术史论到哲学思辨，分享不同领域的智慧结晶。

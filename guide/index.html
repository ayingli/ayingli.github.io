# 关于我

# 你好，我是欧阳敏

我目前主要在写这几类内容：数学、编程和人工智能、经济学、文学艺术和哲学等。编程和人工智能是之前所学专业以及后来参加工作相关的 ，数学一直是比较感兴趣的 ，经济学文学艺术和哲学是在后来的工作过程当中发现的比较有意思的学科 。开了几个公众号想要把这几类内容写出来，也是对自己学习的一个促进和复盘。

# 数学，公众号：中年考生手记

这个公众号本意是想记录作为一名中年考生的学习和日常生活，现在把从小学到大学数学教材相关的学习内容记录在这个公众号中 。也会去记录其他学科方面的基础知识，当是自己的学习笔记吧。

  • 从定义和证明出发，把概念理解透，而不是只给结论。
  • 用数学思维来解决日常生活中的实际问题。

# 编程和人工智能，公众号：派智堂

  • 信奥赛相关，进则科技特长，退则数理化强。
  • 如何用代码快速解决数学问题
  • 用代码写个小工具或者小插件在工作中提高工作效率，减少重复劳动等。
  • 人工智能专业知识：数据分析，计算机视觉，自然语言处理，推荐系统，强化学习，机器学习，深度学习，机器人说等。

# 经济学，公众号：捉虫记

  • 经济学基础概念理解
  • 宏观经济学，微观经济学，国际经济学，金融贸易，经济史等
  • 用经济学解释日常现象，心理学解释决策偏差、非理性行为，拆解对普通人的影响。

# 文学、艺术、哲学，公众号：艺术刊物

  • 一本好书的读后感
  • 一部电影的剧情分析和人物刻画，联系实际生活给了我们什么样的启发
  • 以哲学思想化解内耗与焦虑，看透事情的本质、不被裹挟，建立正确的三观
